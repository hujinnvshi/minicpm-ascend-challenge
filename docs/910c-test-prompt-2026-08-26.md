## 使用方法

1. 910C 上启动 agent（hermes / opencode），粘贴上面整段；或 `hermes chat -q "<提示词>"`（长文本建议交互式）
2. agent 自主完成 探测→clone→构建→基线→精度A/B→优化探索；**精度 A/B 结果先回传**（v8 打包决策不等优化）
3. 每轮优化实验的回传贴回本对话，本机对照段耗时/分布判读，批准下一轮

## 与 v1 的关键差异（为什么这么改）

| 维度 | v1（公共仓库·验证） | v2（完整项目·优化） |
|---|---|---|
| 代码来源 | https 公共仓库（脱敏） | **SSH 完整项目**（git@github.com:...，key 已配） |
| 上下文 | agent 需自带全部信息 | **先读 docs/ 自足**（session/进度/onboarding/优化地图） |
| 任务 | 验证 + 精度冒烟 | 精度冒烟（门禁）→ **继续优化**（Phase 2 候选） |
| 优化部分 | 无 | 假设驱动 + 段耗时分解先行 + 采纳门槛（分布零重叠）+ 候选清单 |
| 构建坑 | README-910C 指引 | 同 + 指向完整项目 docs/910c-cannlab-onboarding |

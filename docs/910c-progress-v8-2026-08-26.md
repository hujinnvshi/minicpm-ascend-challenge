**CANN FA contiguity 缺陷（910C 定位并修复）**：
- 现象：perf-duplex 主 LLM 多 token prefill 崩溃（FusedInferAttentionScore: key must be contiguous）
- 根因：ggml_cann_flash_attn_ext 的 transpose12 假设 K/V/Q head-major [D,N,S]；多 token prefill 是 sequence-major [D,S,N]
- 修复：aclnn_ops.cpp FA 入口非规范视图做连续拷贝（B≤1 忽略 dim3）；perf-duplex 复活、rts 无回归
- 影响：解锁 perf-duplex + prefill 图模式 + 防评测边界崩溃（健壮性必修）

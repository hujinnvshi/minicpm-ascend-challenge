## 七、关键坑（今日新增，均已入 skill）

1. perf-duplex 输出过 `| grep | head` 管道 → **SIGPIPE 杀进程**（stage_timing 停 16 帧）→ 输出重定向文件。
2. TTS_OUTPUT_DIR 子目录必须先 mkdir（fopen 静默失败）。
3. GCC -O3 不向量化 FP 归约循环（`__restrict__` 无效，浮点非结合律是主因）；**别用 NEON 累加器**
   （改变 FP 顺序有数值风险），行间并行是零风险解。
4. 提交前复测纪律：≥3 次独立 run + 分布零重叠 + 机制印证（per-step 预测 vs 官方口径段 delta）。
5. 零影响验证最强形式：同 seed A/B 端到端 wav 逐字节对比（server --seed 固定）。

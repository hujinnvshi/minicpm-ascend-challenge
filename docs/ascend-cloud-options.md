# 昇腾算力公开购买渠道调研（2026-07-31）

> 背景：910C 官方算力排队期间，考虑自费购买昇腾环境提前预演 CANN 链路。
> 结论：公开渠道可买到 910B（非 910C）；910B 可验证链路但正式数据仍需 910C。

## 渠道对比

| 渠道 | 硬件 | 计费 | 特点 |
|---|---|---|---|
| 华为云 ModelArts 昇腾云服务 | 910B（公共/专属池）、310 推理卡 | 按需/包月，NPU 计费 | 最官方；910C 主要走 CloudMatrix384 超节点（大客户），个人买不到 |
| 华为云 ECS 昇腾云服务器 | Ai1s(310 推理) / Physical.KAt1(910B 裸金属) | 按需 | 需华为云账号+实名认证 |
| 星宇智算等垂直昇腾平台 | 910B 32GB 物理独享、4/8 卡液冷 | 小时按需/夜间特惠/包月 | 预装 CANN 7.0+MindSpore+PyTorch 昇腾插件；比公有云便宜约 29%；内网 10Gbps |
| 并行科技 | 910A/910B 裸金属整机 | 5-9 万/台/月 | 面向企业，贵 |
| 阿里云/腾讯云 | 310 推理为主，910B 库存少 | 按需 | 训练场景不推荐 |
| 地方智算中心 | 910B/910C 万卡级 | 整机柜年租 | 政企专属，7-15 天审批，不适合个人 |

## 关键点

1. **910C 公开渠道买不到**——比赛用卡是新一代，主要供给超节点/大客户；公开市场主流是 910B
2. **910B vs 910C**：同代达芬奇架构，CANN 编译/API 兼容，链路预演（编译 llama.cpp、权重传输、
   perf 流程、脚本调试）完全可行；但算子性能与个别行为可能有差异（如 CUDA 上 Q8_0 乱码坑
   在 CANN 上不一定复现），**910B 结果不能进正式报告，910C 必须重测**
3. 成本量级：单卡按需约 10-30 元/小时；链路预演 20-30 卡时 ≈ 300-900 元
4. 购买前提：华为云账号+实名认证（ModelArts），或平台注册（垂直平台）

## 决策建议

- 先查 910C 审批状态（个人中心-通知管理）；3-4 天内能过 → 等官方免费算力
- 审批明显超期 → 买 910B 小时卡预演（星宇智算或 ModelArts），把 CANN 编译/权重/脚本坑提前踩完，
  910C 一到直接走正式流程（30 卡时预算不变）
- 预演内容优先级：CANN 版编译（-DGGML_CANN=ON）→ 权重传输 → 官方 perf 基线 → 候选配置验证 → msprof 摸底
